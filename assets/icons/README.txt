LocalGuard icon assets (generated by scripts/generate_icons.py).

  localguard.ico       multi-resolution application icon (green shield,
                       16-256 px) - embedded in LocalGuard.exe by
                       localguard.spec and used by the installer and
                       shortcuts.
  tray_protected.png   64x64 tray icon - green shield, white check mark.
  tray_paused.png      64x64 tray icon - amber shield, white pause bars.
  tray_warning.png     64x64 tray icon - red shield, white exclamation.
  tray_scanning.png    64x64 tray icon - blue shield, hollow ring (the
                       live tray flashes the overlay frames below while
                       a scan runs; this static variant is kept for
                       future use and completeness).
  tray_protected_overlay_0.png / _1.png
                       64x64 scan-progress overlays composited over the
                       protected shield (blue filled badge / hollow
                       ring). The tray alternates them every 0.6 s to
                       show a live progress hint; the tooltip carries
                       the file count.
  shield_16/32/48.png  UI shield images for in-app use.

Regenerate after changing the palette or geometry:

    .venv\Scripts\python.exe scripts\generate_icons.py

The application falls back to drawing the same shapes with Pillow if
the PNG files are missing, so the tray always works - but the bundled
build ships these files (see localguard.spec datas).
